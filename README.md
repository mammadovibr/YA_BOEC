# Я БОЕЦ

3D-игра в браузере: боксёрский зал, груши на цепях, комбо, контратаки, раунд на 60 секунд,
танец под диско-шаром и сальто. Работает на телефонах (iPhone / Android) и на компьютере,
ставится на главный экран как приложение (PWA).

## Запуск локально

Любой статический сервер из корня репозитория:

```
python3 -m http.server 8080
```

и открыть http://localhost:8080

## Устройство

- `index.html`, `css/`, `js/` — игра (Three.js, без сборки).
- `vendor/three/` — Three.js r170 и нужные дополнения.
- `assets/hero.glb` — персонаж с анимациями (сжат), `assets/gym.glb` — зал из Blender.
- `tools/` — генерация текстур, сборка зала в Blender (`bpy`), сжатие моделей (`tools/build.sh`).
- `sw.js`, `manifest.webmanifest`, `icons/` — офлайн-кэш и установка на телефон.

Все звуки синтезируются в браузере через Web Audio API.
